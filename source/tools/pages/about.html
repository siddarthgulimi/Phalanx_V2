How Phalanx works

Three layers watch your browser so you don't have to.

Phalanx checks every website before it loads, every download as it arrives, and every page for code that sneaks in after loading. When something looks wrong you get one small alert and three simple choices.

Everything runs on your own PC. Nothing is uploaded anywhere.

How a threat is scanned

  1. Watch. The extension sees a new website address, a new download, or a change inside a page (a form, script, frame or overlay added after loading).
  2. Collect evidence. It reads only what matters: the address, the file name and source, or the injected element — never your passwords or page text.
  3. Score 0–100. Each warning sign adds points (e.g. "raw IP address" +30, "brand look-alike" +40, "disguised .pdf.exe" +50). Well-known services like Gmail, Meet, Discord and Netflix are trusted.
  4. Compare with your sensitivity. Low alerts at ≥70, Medium at ≥45, High at ≥20.
  5. Act. High & critical threats can be auto-quarantined instantly; everything else waits for your choice.

Honest limits

  • Not an antivirus: downloads are judged by Chrome Safe Browsing's verdict plus Phalanx's file checks — files are not opened or scanned byte-by-byte.
  • Browser extensions can't read raw network packets; the network graph is a request-rate estimate.
  • Site checks are offline heuristics, not a live threat-intelligence feed.
  • A script that already started running can't be "un-run" — Phalanx removes it and warns you.

Install guide (Windows)

  1. Run Phalanx-Setup.exe (or unzip and run Phalanx.exe directly). If Windows SmartScreen appears, choose More info → Run anyway.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and pick the extension folder inside the Phalanx folder.
  4. Pin the Phalanx icon. The sidebar of this app turns to Extension connected within ~30 seconds.
  5. Open the Test lab from the left menu to see detections live.

The data & cache folder defaults to PhalanxData next to Phalanx.exe and can be moved in Settings → Storage & cache.
